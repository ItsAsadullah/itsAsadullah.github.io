🇧🇩 Complete Bangla Input

Full Avro Phonetic transliteration engine with smart conjuncts (যুক্তবর্ণ), Jatiyo (জাতীয়), and Probhat layouts alongside QWERTY English.

✨ Gemini AI Assistant

In-keyboard grammar correction, tone rewriting, smart replies, custom user prompts, and contextual text generation powered by Gemini AI.

🌐 Live & Offline Translation

Translate Bangla ↔ English and 20+ languages directly inside the keyboard strip without switching apps.

⚡ Corner-Swipe Precision

Swipe toward key corners to type numbers, punctuation, modifiers (`Ctrl`, `Alt`, `Tab`), and diacritics without layout switching.

📋 Smart Clipboard & Safety

Pinned snippets, search, Direct Boot safety, automatic password-field learning lockout, and built-in GitHub release update checker.

🎨 Focus Mode & Themes

Clean Focus Mode that hides extra symbol clutter while preserving essential Bangla sub-keys, plus Material You dynamic themes.
