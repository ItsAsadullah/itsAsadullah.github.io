## 🚀 Flagship Open-Source Project

### ⌨️ [TypoDev Keyboard (`ItsAsadullah/TypoDev`)](https://github.com/ItsAsadullah/TypoDev)
An ultra-lightweight (`< 3 MB`), privacy-first, open-source Android keyboard featuring:
- **🇧🇩 Complete Bangla Typing:** Avro Phonetic (অভ্র ফনেটিক) with smart conjuncts (যুক্তবর্ণ), Jatiyo (জাতীয়), and Probhat layouts + QWERTY English.
- **✨ Gemini AI Writing Assistant:** In-keyboard grammar fix, tone rewrite, smart replies, and custom AI prompts.
- **🌐 Live & Offline Translation:** Instant Bangla ↔ English and multi-language translation inside the suggestion bar.
- **⚡ Corner-Swipe Symbols & Modifiers:** Type numbers, symbols, `Ctrl`, `Alt`, and cursor arrows with quick corner swipes.
- **📥 Download Latest APK:** **[TypoDev v2.1.7 Release](https://github.com/ItsAsadullah/TypoDev/releases/latest)**
